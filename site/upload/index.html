⬆ Upload PDFs on GitHub
  1. A GitHub tab opens, already in the inbox folder (sign in if asked).
  2. Drag your PDFs onto it, or click choose your files.
  3. Wait for the files to finish loading, then press Commit changes.
  4. Come back to this tab. Progress shows below.
